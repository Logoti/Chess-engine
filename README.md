# 🧠 Sobre o Projeto

O **Ghost Layer Absolute** é uma arquitetura experimental de cognição aplicada ao xadrez que adiciona uma camada comportamental sobre um motor de análise tradicional.

Enquanto engines convencionais buscam apenas a melhor decisão matemática de uma posição, o Ghost Layer explora uma abordagem diferente:

> Simular processos de decisão semelhantes aos humanos, considerando contexto, estilo, pressão e limitações cognitivas.

O sistema introduz elementos como:

- Variação controlada de precisão
- Pressão psicológica
- Fadiga cognitiva
- Preferências de estilo
- Tendências comportamentais
- Erros humanos controlados
- Escolhas práticas em vez de apenas ótimas

A proposta explora a interseção entre:

- Inteligência Artificial
- Teoria dos Jogos
- Computação Cognitiva
- Modelagem de Comportamento Humano

# ✨ Principais Funcionalidades

## 🧠 Cognitive Decision Layer

Camada responsável por transformar a avaliação pura do motor em uma decisão com características comportamentais.

Recursos:

- Controle de profundidade cognitiva
- Ajuste de precisão baseado no contexto
- Fadiga progressiva durante a partida
- Influência da pressão de tempo
- Sistema de confiança baseado no histórico recente

---

# 🎭 Personalidades e Estilos de Jogo

O sistema suporta diferentes perfis comportamentais:

| Perfil | Característica |
|---|---|
| 🔥 Agressivo | Busca iniciativa, ataques e posições complexas |
| 🧱 Posicional | Prioriza estrutura, espaço e controle |
| 🛡️ Sólido | Minimiza riscos e prefere segurança |
| 🎨 Criativo | Busca ideias incomuns e recursos inesperados |
| ⚡ Prático | Prioriza decisões eficientes sob pressão |

Cada personalidade influencia:

- Preferência de movimentos
- Escolha de planos estratégicos
- Tolerância a risco
- Tendência de simplificação
- Comportamento em posições críticas

---

# 📖 Opening Book System

Sistema de livro de aberturas integrado para condução inicial da partida.

Características:

- Desenvolvimento inicial consistente
- Preparação de repertório
- Controle de variação comportamental
- Transição gradual para cálculo próprio

Suporte:

- Peças brancas
- Peças pretas
- Ajuste de variação humana durante a abertura

---

# 🛡️ Blindagem de Estado do Tabuleiro

Camada responsável pela leitura e sincronização confiável do ambiente.

Recursos:

- Leitura do estado real do tabuleiro
- Proteção contra animações de peças
- Detecção de mudanças via DOM
- Recuperação automática de inconsistências

---

# 👁️ Shadow Interface Layer

Sistema visual isolado utilizando **Closed Shadow DOM**.

Características:

- Interface independente do layout original
- Canvas flutuante
- Renderização limpa das informações
- Baixa interferência visual

---

# ❤️ Watchdog & Auto Recovery

Sistema de estabilidade da comunicação.

Inclui:

- Heartbeat automático
- Monitoramento WebSocket
- Reconexão automática
- Recuperação contra falhas temporárias
